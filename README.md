# Pantalla en Ángulo

Calcula el campo de visión geométrico de una pantalla plana y la distancia para un FOV objetivo. Distingue horizontal y vertical, sin ajustes inventados por juego.

GitHub Pages: main, raiz. https://ilga25.github.io/pantalla-en-angulo/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
